# Screenshots

Screenshots of the dashboard can be placed here. To capture them:

1. Start the Klip backend: `cd src-tauri && cargo run`
2. Start the dev server: `cd web-klip && pnpm dev`
3. Open http://localhost:5173 in your browser
4. Capture screenshots of key pages (Clipboard, Search, Stats, QA, Events, etc.)

Screenshots were not generated during the CI/build session because the environment lacks a display server.
