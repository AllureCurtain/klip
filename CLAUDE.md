# CLAUDE.md

Project guidance for AI agents lives in **`AGENTS.md`** (root), with
directory-specific rules in `src/AGENTS.md` and `src-tauri/AGENTS.md`. Read
those first — they are the single source of truth for conventions, commands,
and hard rules.

`docs/INDEX.md` is the documentation entry point; `docs/decisions.md` records
technical decisions including the doc-layout migration.

This file is kept temporarily as a pointer for tools that only read
`CLAUDE.md`; it will be removed once `AGENTS.md` support is confirmed for all
contributors (see `docs/decisions.md` D-0001).
